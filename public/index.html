Bitcoin · Herramienta web

IBIT to BTC

Un conversor para entender cuánto Bitcoin representan tus cuotas de IBIT o CEDEAR y calcular el costo equivalente por BTC desde tu precio promedio de compra.

En ambas versiones, los cálculos usan precisión decimal; cada dato muestra su fuente y fecha. Si una cotización no se actualiza, conserva su fecha original y avisa su antigüedad.

Argentina
En español, con CEDEAR, cuotas de IBIT, BTC, satoshis, ARS y USD MEP/CCL.
Internacional
En inglés, con cuotas de IBIT, BTC, satoshis y USD.

Juego · Sistemas en tiempo real

Truco a 3 puntos

Una variante propia del truco argentino, con una web para jugar online, invitar amigos o enfrentarte a bots.

El frontend en Angular lleva la mesa a móvil y escritorio, con partida rápida, modo campaña, perfiles y logros.

Las reglas del juego viven en un dominio separado de la infraestructura. Spring Boot, WebSocket y PostgreSQL permiten gestionar partidas y torneos, comunicar los cambios y persistir el estado.

Bitcoin · Automatización

BTC Unspendable Bot

Un bot para X (Twitter) que publica cada día el total de BTC que Bitcoin Core clasifica como imposibles de gastar y su variación desde el registro anterior.

Calcula los cambios con precisión en satoshis y guarda el registro en Git solo cuando X confirma la publicación. Se ejecuta con Node.js y GitHub Actions, con autenticación OAuth 2.0 y rotación de credenciales.

Bitcoin · Integración de sistemas

De tablet a nodo Bitcoin

Reutilicé una tablet LG G Pad 8.0 V480 de 2014, con 1 GB de RAM y una microSD de 32 GB, para validar Bitcoin con un nodo podado y un panel Android propio.

Integré LineageOS 14.1, Termux, Bitcoin Core y Tor con arranque automático y recuperación de Wi-Fi. Una API local conecta el nodo con la app.

Para reducir el consumo de memoria, reemplacé la WebView por una interfaz nativa en Java y optimicé las consultas. Un servicio en C controla la carga de la batería entre el 50 % y el 70 %.
